# awesome-fire-data

A curated catalog of fire-related datasets.

Site: https://noahweidig.com/awesome-fire-data/

Datasets live in `data/datasets/*.yml`. See the [Contribute page](https://noahweidig.com/awesome-fire-data/contribute/) to add one.

```bash
pip install -r requirements.txt
python scripts/generate.py
zensical serve
```
