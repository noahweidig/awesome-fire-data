# Fire behavior software

Desktop tools from the USFS Missoula Fire Sciences Laboratory. They take the fuel, terrain and weather layers listed under [Fuels, vegetation & terrain](../datasets/fuels-terrain/index.md) and [Weather, climate & danger](../datasets/weather-danger/index.md).

| Tool | What it does | Platform | Notes |
| --- | --- | --- | --- |
| [FlamMap](https://research.fs.usda.gov/firelab/products/dataandtools/flammap){ title="Fire analysis desktop application" } | Simulates fire behavior (spread rate, flame length, fireline intensity), fire growth and conditional burn probability | 64-bit Windows only | Version 6 includes FARSITE. No map interface. Needs a landscape file, for example from [LANDFIRE](../datasets/fuels-terrain/landfire.md). |
| [FARSITE](https://research.fs.usda.gov/firelab/products/dataandtools/farsite){ title="Fire Area Simulator" } | Fire growth simulation under changing weather, terrain and fuels | Through FlamMap | The standalone FARSITE4 is no longer supported or available for download. Use FlamMap 6. |
| [Behave and BehavePlus](https://www.frames.gov/behaveplus/home){ title="Fire behavior modeling system" } | Predicts fire behavior for point scenarios such as flame length, spread rate and spotting distance | Windows, macOS, Linux (Behave 7) | The project now presents Behave 7 as the current system. |

Check each tool's page for the current version and license terms before use.
