# Glossary

Acronyms across the site show a tooltip on hover. The full list:

API
:   Application Programming Interface

CONUS
:   Conterminous United States

DEM
:   Digital Elevation Model

FRP
:   Fire Radiative Power, the rate of radiant heat output of a fire in megawatts

FWI
:   Fire Weather Index, a component of the Canadian Forest Fire Danger Rating System

GOES
:   Geostationary Operational Environmental Satellite

MODIS
:   Moderate Resolution Imaging Spectroradiometer

NFDRS
:   National Fire Danger Rating System

PM2.5
:   Fine particulate matter, 2.5 micrometers or smaller

STAC
:   SpatioTemporal Asset Catalog

VIIRS
:   Visible Infrared Imaging Radiometer Suite

WUI
:   Wildland-Urban Interface, where homes meet or intermingle with wildland vegetation
