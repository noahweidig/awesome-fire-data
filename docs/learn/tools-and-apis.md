# Tools and APIs

## Platforms

- [Google Earth Engine](https://earthengine.google.com/){ title="Planetary-scale geospatial analysis" } hosts many fire products next to Landsat, Sentinel and MODIS archives.
- [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com){ title="STAC catalog with Python access" } serves cloud-optimized data through a STAC API.
- [STAC](https://stacspec.org){ title="SpatioTemporal Asset Catalog" } is the metadata standard many cloud catalogs share.
- [earthaccess](https://earthaccess.readthedocs.io/){ title="NASA Earthdata search and download from Python" } searches and downloads NASA data such as MODIS, VIIRS and GEDI.
- [AWS Open Data Registry](https://registry.opendata.aws/){ title="Public datasets in S3" } hosts HRRR and GOES.

## Desktop GIS

- [QGIS](https://qgis.org/){ title="Free desktop GIS" } opens GeoTIFF, shapefile, GeoPackage and geodatabase files.

## Python libraries

- [rasterio](https://rasterio.readthedocs.io) for rasters.
- [geopandas](https://geopandas.org) for vector data.
- [xarray](https://docs.xarray.dev) for gridded arrays such as NetCDF and GRIB.
- [geemap](https://geemap.org) for Earth Engine in Python.
- [Herbie](https://herbie.readthedocs.io) for downloading HRRR and other model output.

## R packages

- [terra](https://rspatial.github.io/terra/) for rasters and vectors.
- [rgee](https://r-spatial.github.io/rgee/) for Earth Engine from R.
- [rapr](https://cran.r-project.org/package=rapr) for Rangeland Analysis Platform grids.
- [rFIA](https://rfia.netlify.app/) and [FIESTA](https://cran.r-project.org/package=FIESTA) for Forest Inventory and Analysis data.
