# About

Awesome Fire Datasets is a community catalog of fire-related data. It lists where data lives and how it is licensed. It does not host the data.

## Scope

Wildland fire data worldwide, with the strongest coverage of the United States for now. Structural fire and fire-department data are out of scope.
