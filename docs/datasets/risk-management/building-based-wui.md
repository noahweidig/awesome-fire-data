# Building-based WUI maps (CONUS)

Intermix and interface WUI maps for the conterminous US built from 125 million building point locations, at several neighborhood radii.

[:lucide-download: Access data](https://doi.org/10.5066/P94BT6Q7){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.1002/eap.2597){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | USGS, with University of Wisconsin-Madison SILVIS Lab |
| :lucide-map:{ title="Geographic extent" } Coverage | Conterminous United States |
| :lucide-calendar:{ title="Years covered" } Period | Buildings from a 2018 release; vegetation from NLCD 2016 |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 30 m |
| :lucide-file:{ title="File and service formats" } Format | GeoTIFF |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | See ScienceBase record |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Static |

!!! warning "Caveat"

    Single 16.9 GB zip. Building locations come from a Microsoft 2018 product, so newer construction is missing. Check the record for the file format.
