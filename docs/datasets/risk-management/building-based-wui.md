# Building-based WUI maps (CONUS)

Intermix and interface WUI maps for the conterminous US built from 125 million building point locations, at several neighborhood radii.

[:lucide-download: Access data](https://doi.org/10.5066/P94BT6Q7){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.1002/eap.2597){ .md-button }
