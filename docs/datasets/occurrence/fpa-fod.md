# FPA-FOD (Fire Program Analysis Fire-Occurrence Database)

Point locations, discovery dates, causes and sizes of 2.66 million US wildfires from federal, state and local records.

[:lucide-download: Access data](https://www.fs.usda.gov/rds/archive/catalog/RDS-2013-0009.7){ .md-button .md-button--primary }
