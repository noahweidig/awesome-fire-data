# GlobalRx

204,517 georeferenced prescribed burn records from 16 countries, with weather and environmental context for each burn.

[:lucide-download: Access data](https://doi.org/10.5281/zenodo.13379462){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.1038/s41597-025-04941-w){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | Hsu et al. (University of East Anglia and collaborators) |
| :lucide-map:{ title="Geographic extent" } Coverage | 16 countries |
| :lucide-calendar:{ title="Years covered" } Period | 1979 to 2023 |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | Burn records (points) |
| :lucide-file:{ title="File and service formats" } Format | CSV, Shapefile |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | CC BY 4.0 |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Static |

!!! warning "Caveat"

    Coverage is uneven across countries because each source database differs in reporting.
