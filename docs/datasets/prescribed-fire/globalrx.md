# GlobalRx

204,517 georeferenced prescribed burn records from 16 countries, with weather and environmental context for each burn.

[:lucide-download: Access data](https://doi.org/10.5281/zenodo.13379462){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.1038/s41597-025-04941-w){ .md-button }
