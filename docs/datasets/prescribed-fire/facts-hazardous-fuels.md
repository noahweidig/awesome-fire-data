# USFS Hazardous Fuel Treatment Reduction (FACTS)

Polygon and line records of Forest Service hazardous fuel treatments, including prescribed burning, from the FACTS activity tracking system.

[:lucide-download: Access data](https://data.fs.usda.gov/geodata/edw/datasets.php){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://catalog.data.gov/dataset/hazardous-fuel-treatment-reduction-polygon-feature-layer){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | USDA Forest Service |
| :lucide-map:{ title="Geographic extent" } Coverage | United States (Forest Service activities) |
| :lucide-calendar:{ title="Years covered" } Period | Ongoing |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | Polygons and lines |
| :lucide-file:{ title="File and service formats" } Format | GeoDatabase, Shapefile, GeoJSON, KML, CSV |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | CC BY 4.0 |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Ongoing |

!!! warning "Caveat"

    Records planned and accomplished treatments reported by the Forest Service. Other agencies are not included.
