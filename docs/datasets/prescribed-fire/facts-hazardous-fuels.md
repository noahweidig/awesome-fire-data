# USFS Hazardous Fuel Treatment Reduction (FACTS)

Polygon and line records of Forest Service hazardous fuel treatments, including prescribed burning, from the FACTS activity tracking system.

[:lucide-download: Access data](https://data.fs.usda.gov/geodata/edw/datasets.php){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://catalog.data.gov/dataset/hazardous-fuel-treatment-reduction-polygon-feature-layer){ .md-button }
