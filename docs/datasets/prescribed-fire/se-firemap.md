# Southeast FireMap Burned Area (SE FireMap)

Annual Landsat burned area for the southeastern US, covering prescribed fire and wildfire, with burn date and burn probability.

[:lucide-download: Access data](https://www.sciencebase.gov/catalog/item/686e946dd4be020e5c0a67d0){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.5066/P1PVDTVK){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | USGS and Tall Timbers Research Station |
| :lucide-map:{ title="Geographic extent" } Coverage | Southeastern US |
| :lucide-calendar:{ title="Years covered" } Period | 1994 to 2025 |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 30 m |
| :lucide-file:{ title="File and service formats" } Format | GeoTIFF |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | CC0 |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Annual |

!!! warning "Caveat"

    Covers prescribed fire and wildfire together. The 30 m resolution can miss small burns. Vector polygons are released separately.
