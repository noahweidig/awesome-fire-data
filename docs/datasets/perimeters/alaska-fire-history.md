# Alaska Fire History (BLM AFS)

Statewide Alaska fire perimeter polygons and ignition points from the BLM Alaska Fire Service.

[:lucide-download: Access data](https://fire.ak.blm.gov/predsvcs/maps.php){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://fire.ak.blm.gov/predsvcs/maps.php){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | BLM Alaska Fire Service and Alaska Interagency Coordination Center |
| :lucide-map:{ title="Geographic extent" } Coverage | Alaska |
| :lucide-calendar:{ title="Years covered" } Period | 1940 to 2025 |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | Vector |
| :lucide-file:{ title="File and service formats" } Format | ArcGIS feature service, Shapefile |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | See BLM AFS terms |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Annual |
| :lucide-badge-check:{ title="Date this entry was last checked against the provider" } Last verified | 2026-11-09 |

!!! warning "Caveat"

    The record does not include every fire, and polygons are less complete than points. Some older polygons were flagged for geospatial inaccuracies. Check the download page for current file formats.
