# CAL FIRE FRAP Historical Fire Perimeters

California fire perimeters from 1878 to the latest fire season, from CAL FIRE's Fire and Resource Assessment Program.

[:lucide-download: Access data](https://catalog.data.gov/dataset/california-fire-perimeters-all){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://lab.data.ca.gov/dataset/california-fire-perimeters-all){ .md-button }

!!! warning "Caveat"

    Updated each spring with the prior fire season. CAL FIRE says the record is the most complete digital one for California but still incomplete, especially before 1950. Inclusion thresholds can differ from NIFC data.
