# MTBS (Monitoring Trends in Burn Severity)

Burn severity mosaics and perimeters for large US fires, mapped from Landsat.

[:lucide-download: Access data](https://www.mtbs.gov/direct-download){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://www.mtbs.gov/){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | USGS EROS and USDA Forest Service |
| :lucide-map:{ title="Geographic extent" } Coverage | CONUS, Alaska, Hawaii, Puerto Rico |
| :lucide-calendar:{ title="Years covered" } Period | 1984 to present |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 30 m |
| :lucide-file:{ title="File and service formats" } Format | GeoTIFF, Shapefile |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | Public domain |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Annual |

!!! warning "Caveat"

    Covers fires of at least 1,000 acres in the West and 500 acres in the East. Includes prescribed fire perimeters. See Prescribed fire & fuel treatments for other prescribed burn sources.
