# NBAC (National Burned Area Composite)

Annual Canadian burned area polygons compiled from provincial, territorial, Parks Canada and satellite sources.

[:lucide-download: Access data](https://cwfis.cfs.nrcan.gc.ca/datamart/download/nbac){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://cwfis.cfs.nrcan.gc.ca/datamart/metadata/nbac){ .md-button }
