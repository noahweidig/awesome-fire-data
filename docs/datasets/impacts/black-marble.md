# NASA Black Marble Nighttime Lights

Daily, monthly and annual nighttime lights from VIIRS, used to track power loss and recovery after disasters.

[:lucide-download: Access data](https://blackmarble.gsfc.nasa.gov/){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://blackmarble.gsfc.nasa.gov/){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | NASA Goddard (Black Marble) |
| :lucide-map:{ title="Geographic extent" } Coverage | Global |
| :lucide-calendar:{ title="Years covered" } Period | 2012 to present |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 500 m |
| :lucide-file:{ title="File and service formats" } Format | HDF |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | NASA open data |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Daily |

!!! warning "Caveat"

    Cloud cover and smoke can hide lights on a given night.
