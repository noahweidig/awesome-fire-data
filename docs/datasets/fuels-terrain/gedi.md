# GEDI Spaceborne Lidar

Lidar footprints with canopy height, cover, vertical structure and biomass from the International Space Station.

[:lucide-download: Access data](https://lpdaac.usgs.gov/products/gedi02_av002/){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://gedi.umd.edu/data/products/){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | NASA, University of Maryland |
| :lucide-map:{ title="Geographic extent" } Coverage | Global, between 51.6 degrees N and S |
| :lucide-calendar:{ title="Years covered" } Period | 2019 to present |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 25 m footprints |
| :lucide-file:{ title="File and service formats" } Format | HDF |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | NASA open data |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Ongoing |

!!! warning "Caveat"

    Footprints are sparse samples along orbit tracks, not wall-to-wall maps.
