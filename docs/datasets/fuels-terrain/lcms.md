# LCMS Landscape Change Monitoring System

Annual landscape change, land cover and land use from Landsat and Sentinel-2 time series.

[:lucide-download: Access data](https://data.fs.usda.gov/geodata/rastergateway/LCMS/){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://data.fs.usda.gov/geodata/rastergateway/LCMS/LCMS-Project-Overview.pdf){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | USDA Forest Service GTAC |
| :lucide-map:{ title="Geographic extent" } Coverage | CONUS, Alaska, Hawaii, Puerto Rico and US Virgin Islands |
| :lucide-calendar:{ title="Years covered" } Period | 1985 to 2024 |
