# RCMAP Rangeland Condition Monitoring

Yearly fractional cover of shrub, sagebrush, herbaceous, litter, bare ground and tree for western rangelands.

[:lucide-download: Access data](https://www.mrlc.gov/data){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.5066/P138CYEL){ .md-button }
