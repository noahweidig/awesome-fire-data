# FIRED (Fire Events Delineation)

Fire event polygons with daily spread estimates built by grouping MODIS burned area pixels in space and time.

[:lucide-download: Access data](https://scholar.colorado.edu/concern/datasets/v405sc03w){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.3390/rs12213498){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | Earth Lab, University of Colorado Boulder |
| :lucide-map:{ title="Geographic extent" } Coverage | United States, with regional releases elsewhere |
| :lucide-calendar:{ title="Years covered" } Period | 2001 to 2019 (US) |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 500 m |
| :lucide-file:{ title="File and service formats" } Format | Shapefile, GeoPackage |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | See dataset record |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Static |

!!! warning "Caveat"

    Event parameters differ between regional releases. Check the record for the version and MODIS collection used.
