# FIRED (Fire Events Delineation)

Fire event polygons with daily spread estimates built by grouping MODIS burned area pixels in space and time.

[:lucide-download: Access data](https://scholar.colorado.edu/concern/datasets/v405sc03w){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://doi.org/10.3390/rs12213498){ .md-button }
