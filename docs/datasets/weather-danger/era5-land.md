# ERA5-Land

Hourly global land surface reanalysis of temperature, soil moisture, wind, radiation and precipitation.

[:lucide-download: Access data](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land){ .md-button }
