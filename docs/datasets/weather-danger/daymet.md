# Daymet

Daily 1 km gridded surface weather (temperature, precipitation, radiation, humidity, snow water equivalent) for North America.

[:lucide-download: Access data](https://daymet.ornl.gov/getdata){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://daymet.ornl.gov/overview){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | NASA ORNL DAAC |
| :lucide-map:{ title="Geographic extent" } Coverage | North America |
| :lucide-calendar:{ title="Years covered" } Period | 1980 to present |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 1 km |
| :lucide-file:{ title="File and service formats" } Format | NetCDF |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | NASA open data |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Annual |

!!! warning "Caveat"

    Covers weather variables only. Fire danger indices must be derived.
