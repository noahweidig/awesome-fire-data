# LIS/OTD Gridded Lightning Climatology

Space-based lightning climatologies from the TRMM Lightning Imaging Sensor and the Optical Transient Detector.

[:lucide-download: Access data](https://ghrc.nsstc.nasa.gov/pub/lis/climatology/){ .md-button .md-button--primary }
[:lucide-book-open: Documentation](https://ghrc.nsstc.nasa.gov/uso/ds_details/collections/loCv2.3.2015.html){ .md-button }

## At a glance

| Field | Value |
| --- | --- |
| :lucide-building-2:{ title="Who publishes the data" } Provider | NASA GHRC DAAC |
| :lucide-map:{ title="Geographic extent" } Coverage | Global (about 38 degrees N to S for LIS) |
| :lucide-calendar:{ title="Years covered" } Period | May 1995 to 2013 (V2.3.2015) |
| :lucide-ruler:{ title="Pixel size, grid spacing or feature type" } Resolution | 0.5 and 2.5 degrees |
| :lucide-file:{ title="File and service formats" } Format | HDF, NetCDF |
| :lucide-scale:{ title="Terms of use. Check the provider before redistributing" } License | NASA open data |
| :lucide-refresh-cw:{ title="How often new data is published" } Updates | Static |

!!! warning "Caveat"

    A climatology, not event-level data. Use GLM for recent individual strikes.
