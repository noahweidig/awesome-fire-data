# GOES Geostationary Lightning Mapper (GLM) on AWS

Lightning flash, group and event detections over the Americas from GOES-R satellites.

[:lucide-download: Access data](https://registry.opendata.aws/noaa-goes/){ .md-button .md-button--primary }

## At a glance

| Field | Value |
| --- | --- |

| :lucide-map:{ title="Geographic extent" } Coverage | Americas and adjacent oceans |
| :lucide-calendar:{ title="Years covered" } Period | 2017 to present |
