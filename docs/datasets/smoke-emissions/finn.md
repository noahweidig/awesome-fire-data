# FINN (Fire INventory from NCAR)

Daily, high-resolution fire emissions estimates for chemical transport models.

!!! warning "Caveat"

    The FINNv2.5 documentation I could check lists input fire data through 2020 (README, February 2022). Confirm the latest year on the NCAR ACOM or GDEX pages. ACOM files are gzip-compressed comma-delimited text, one file per year.
